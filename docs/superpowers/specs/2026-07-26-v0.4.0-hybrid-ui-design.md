# JW Converter v0.4.0 — hybrid UI revamp

**Version:** v0.4.0  
**Status:** Shipped (v0.4.0)  
**Date:** 2026-07-26

## Goal

Revamp the **whole** app UI so it feels modern (cobalt.tools shell energy), not a 2020 card stack. Keep Attachment file queues for real batch work.

## Direction (C — hybrid)

| Layer | Look |
|---|---|
| Shell | Near-black canvas, thin left icon rail (Audio / Images / Settings), generous center stage |
| Mode | Pill / rail selection (not stacked “Audio / Images” chips in a header essay) |
| Queues | Keep Attachment rows (idle / converting / done / error + retry) |
| Controls | Pill segmented chips, tight panels, monospace micro-labels |
| Settings | Same visual language: wide dialog, left nav, breadcrumb — still only General / Updates / About / Advanced |

## Non-goals

- Fake SaaS settings pages  
- Cobalt link-paste workflow (we are local file convert)  
- Changing conversion pipelines  

## Success

- First open reads as a modern tool, not a form dashboard  
- Audio ↔ Images via rail; Settings via rail  
- Attachment queues still clear and usable  
- Typecheck green; ship as v0.4.0
