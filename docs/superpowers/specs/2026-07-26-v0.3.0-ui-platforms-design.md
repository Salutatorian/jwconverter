# JW Converter v0.3.0 — design

**Version:** v0.3.0  
**Status:** Implemented (pending signed Windows publish)  
**Date:** 2026-07-26

## Goals

1. **UI redo** — Attachment-style file rows + Settings sidebar dialog (converter sections only).  
2. **Mac + Linux** — GitHub Actions CI builds; Windows remains primary day-to-day.  
3. **One batched release** — no micro versions.

## UI

### File queue → Attachment states

Local convert mapping (copy never says “upload”):

| Job status | Attachment `state` | Description |
|---|---|---|
| ready, queued, skipped, cancelled | idle | Ready / Queued / Skipped / Cancelled |
| analyzing | processing | Analyzing… |
| converting | uploading | Converting · N% |
| verifying | processing | Verifying… |
| completed | done | Done · size |
| failed | error | Error text + Retry |

Primitives: `Attachment*` + `Spinner` + lucide icons. Shared by Audio + Images queues.

### Settings dialog (A)

Sidebar: **General** · **Updates** · **About** · **Advanced**  
- General: short product/mode copy  
- Updates: existing updater  
- About: version + FFmpeg/Magick licensing  
- Advanced: media tools status (read-only)  

Replace current Settings modal. Visual language matches reference (dark, sidebar highlight, breadcrumb header).

### Main shell

Keep Audio/Images logic; restyle drop zone, chips, panels to match attachment/settings look.

## Platforms

- CI: `windows-latest`, `macos-latest`, `ubuntu-latest`  
- Bundle FFmpeg (+ Magick where applicable) per OS  
- macOS: unsigned initially; document Gatekeeper + future notarization  
- Linux: AppImage (or deb)  
- Updater: extend platforms in `latest.json` when CI artifacts exist  

## Non-goals

- Fake SaaS settings pages (Notifications, Connected accounts, …)  
- Apple notarization in 0.3.0 without Developer ID  
- Cloud upload semantics  

## Success

- Windows app: new queue + settings UX, typecheck green  
- CI produces Win + macOS + Linux artifacts on tag/release  
- Signed Windows ship + release notes for 0.3.0
